<task type="auto">
  <name>Task 1: Extract all SCSS variables and CSS custom properties into audit JSON</name>
  <files>tokens/audit/theme-audit.json</files>
  <action>
Read every SCSS file in forms-flow-theme/scss/ (including subdirectories v8-scss/, utils/, external/). For each file, extract:

1. **SCSS Variables** ($variable-name declarations):
   - Variable name (e.g., "$primary")
   - Value as written (e.g., "#253DF4" or "$base*0.78")
   - Computed/resolved value where determinable (e.g., for "$base*0.78" where $base is 0.5rem, note "0.39rem")
   - For variables referencing CSS custom properties (e.g., "$gray-darkest: var(--ff-gray-darkest)"), note the indirection
   - Category/type: color, spacing/dimension, typography, border-radius, shadow, transition, other

2. **CSS Custom Properties** (--property-name in :root blocks):
   - Property name (e.g., "--spacer-100")
   - Value (e.g., "1rem")
   - Category/type: same categories as above
   - Which :root block it appears in (there are TWO :root blocks: one in _theme.scss, one in v8-scss/_theme.scss)

3. **SCSS Maps** ($theme-colors, $custom-colors, $brand-colors, $base-colors, $neutral-colors, $font-tokens, $opacities):
   - Map name
   - All key-value pairs with resolved values

4. **SCSS Mixins and Functions** that generate design values:
   - Mixin name, parameters, what design values they produce
   - The blend-with-white-to-hex function and its role in generating color variants

5. **References**: For each variable/property, scan ALL theme SCSS files to find where it is used (not just declared). Record file path and line number of each usage.

6. **Bootstrap overrides**: The theme imports Bootstrap's _variables.scss after its own _variables.scss (see index.scss import order). Identify which SCSS variables override Bootstrap defaults. For key overrides ($primary, $success, $theme-colors, $btn-color), document the Bootstrap default alongside the project override.

Structure the JSON following the research schema pattern:
```json
{
  "metadata": {
    "auditDate": "YYYY-MM-DD",
    "sourceDirectory": "forms-flow-theme/scss",
    "totalFiles": N,
    "totalVariables": N,
    "totalCustomProperties": N,
    "totalMaps": N
  },
  "scssVariables": {
    "$variable-name": {
      "value": "original expression",
      "computedValue": "resolved value or null if indeterminate",
      "type": "color|dimension|typography|borderRadius|shadow|transition|other",
      "category": "color|spacing|typography|border-radius|shadow|transition|other",
      "sourceFile": "relative/path.scss",
      "sourceLine": N,
      "references": [
        {"file": "relative/path.scss", "line": N, "context": "usage context"}
      ],
      "usageCount": N,
      "isBootstrapOverride": false,
      "bootstrapDefault": null
    }
  },
  "cssCustomProperties": {
    "--property-name": {
      "value": "...",
      "type": "...",
      "category": "...",
      "sourceFile": "...",
      "sourceLine": N,
      "rootBlock": "theme|v8-theme",
      "references": [...],
      "usageCount": N
    }
  },
  "scssMaps": {
    "$map-name": {
      "sourceFile": "...",
      "entries": {
        "key": {"value": "...", "computedValue": "..."}
      }
    }
  },
  "scssMixins": {
    "mixin-name": {
      "sourceFile": "...",
      "parameters": [...],
      "designValuesProduced": "description"
    }
  },
  "scssFunctions": {
    "function-name": {
      "sourceFile": "...",
      "purpose": "...",
      "designImpact": "description"
    }
  }
}
```

Important notes:
- The two :root blocks (in _theme.scss and v8-scss/_theme.scss) have OVERLAPPING custom properties (e.g., --spacer-* appears in both). Document both sources, noting the v8 version likely takes precedence due to import order in index.scss.
- Some SCSS variables like $gray-darkest use var(--ff-gray-darkest) which references a CSS custom property with the "ff-" prefix. Track these cross-references.
- The $danger variable is defined as var(--default-danger-color) AFTER the :root block. Note this pattern.
- v8-scss/_theme.scss uses @each loops to generate CSS custom properties from SCSS maps ($base-colors x $opacities, $brand-colors, $neutral-colors, $font-tokens). Expand these loops to list all generated custom properties.
