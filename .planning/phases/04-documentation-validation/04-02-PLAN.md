**figma-import.md** — Designer-facing Token Studio import guide. Minimal jargon, step-by-step (per user decision: "screenshot-heavy walkthrough, step-by-step, minimal jargon").

Structure:
1. Title: "Importing Design Tokens to Figma"
2. Brief intro: "This guide walks you through importing design tokens into Figma using the Token Studio plugin. No coding experience required."
3. Target audience: Designers using Figma
4. Time required: 10 minutes
5. Prerequisites section with checklist:
   - Figma Desktop app installed (link to download)
   - Token Studio plugin installed (link to Figma Community plugin page)
   - Access to token JSON files: tokens/core.json and tokens/semantic.json
6. Step 1: Open Token Studio Plugin
   - Open Figma file
   - Go to Plugins → Token Studio for Figma (or search in plugin menu)
   - If first time: click "New empty file"
   - Describe what the plugin panel looks like
7. Step 2: Import Core Tokens
   - In Token Studio sidebar, click the "Load" or gear icon
   - Select "JSON" as sync method
   - Click "Import" and choose tokens/core.json from the repository
   - Review token list — expect to see color, spacing, typography, radius, shadow categories under "ff" group
   - Click "Import" to confirm
   - Describe expected result: new token set named based on file
8. Step 3: Import Semantic Tokens
   - Repeat import process with tokens/semantic.json
   - Semantic tokens will show reference syntax (e.g., {ff.color.indigo-100})
   - Must import AFTER core tokens so references resolve
9. Step 4: Sync to Figma Variables
   - In Token Studio, go to "Styles & Variables" section
   - Click "Export to Figma" or "Sync Variables"
   - Select which token sets to sync (both core and semantic)
   - Tokens become Figma Variables usable in designs
10. Step 5: Verify Import
    - Open Variables panel in Figma (right sidebar → Variables icon)
    - Confirm variable collections exist with token categories
    - Spot-check a few values: pick a color token, verify hex matches core.json
    - Check a semantic token references resolve (shows resolved color, not reference text)
11. Troubleshooting section:
    - "Invalid token name" error: forbidden characters in names ({, }, $)
    - References not resolving: import core.json before semantic.json
    - Duplicate variables: delete existing token sets before re-importing
    - Plugin not showing: ensure Token Studio is installed from Figma Community
12. Next Steps: Apply to designs, create modes (light/dark), export changes back
13. References: Token Studio docs, Figma Variables help center

Use plain language throughout. Replace jargon: "DTCG format" → "token format that Figma understands", "reference resolution" → "tokens that point to other tokens".
